# Brand New Start — Command Center (prototype)

Slim commandocentrum voor IT-contracting: waar is nú contracting-ruimte, en wat is de volgende actie.

## Start

```bash
npx serve .
```

http://localhost:3456 · demo via de **Demo**-knop of `?demo=1`

## Schermen

| View | Doel |
|------|------|
| **Radar** | Contracting-kansen per bedrijf: HM, laatste gesprek, kans-score + trend, filters (Hot / Gesprek gaande / Contract-ready), alerts |
| **Plaatsing** | Adyen-case door de 8-stappen flow — agents doen het werk, jij keurt goed |
| **Outreach** | Persoonlijk HM-bericht per hot lead, klaar om te versturen |
| **Pulse** (`/pulse.html`) | Deelbaar formulier: kandidaat krijgt tariefsnapshot, radar krijgt interview-intel |

## Data

Alles mock in `data.js` — later te vervangen door RPS-export, ATS-sync en Pulse-inzendingen.
